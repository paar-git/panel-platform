WHAT'S NEW
Your projects run on your machine, not in a container
Host mode is now how a project runs: the application starts the process itself, watches it, restarts it when it dies and stops it when you quit. Docker is no longer something you install before you can run your own code on your own computer.
A static site serves itself
The application now carries a small read-only HTTP server and uses it, so a static site needs neither a container nor a language it does not use.
Discord bots actually connect
A bot is added by its token, which is stored on this machine and never sent anywhere else.
